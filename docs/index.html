DialDo

Give your Mac a phone number. Call it from anywhere and ask it to do a task.

A local-first voice agent. You call a personal number, speak naturally and confirm once. A cloud gateway routes the call to the desktop app on your Mac, which finds files, summarizes PDFs, writes documents and sends email, then tells you how it went.

  • The phone service and the computer are separated. The Mac dials out to the gateway over an authenticated connection, so nothing exposes a remote shell.
  • Caller number plus a spoken PIN, then one confirmation for the whole task before the first side effect.
  • It checks tool evidence before it says a task is done. Opening an app is not proof the file was sent.
  • Plugin-based tool registry, SQLite task history, signed and notarized for macOS.

Reporun

Know what a repo needs before you run it.

A free desktop app for anyone who has cloned a project and lost an afternoon to setup. Paste a public GitHub or GitLab link. It reads the manifests, compares the requirements with your machine and lists what is missing in plain language.

  • Inspection is pinned to an immutable commit, so the report describes exactly what you are about to run.
  • Nothing installs, downloads or runs without an explicit command preview first.
  • Google sign-in through the system browser with PKCE and a loopback callback. Tokens live in OS-backed secure storage, never in the renderer.
  • Mac installers are Developer ID signed and notarized for Apple silicon and Intel. Windows ships as a preview.

Remote Window

Share one Mac window, not your whole screen.

A native macOS host captures a single window with its audio and streams it over WebRTC to any phone, tablet or browser. The viewer installs nothing. They open a link or scan a code, you approve them on the Mac, and they can watch or take touch control.

  • Least privilege by design. One window leaves the machine, and every viewer is approved by hand.
  • Sessions carry a timer from one hour to a day, and a link can be revoked at any moment.
  • Touch input from the viewer (tap, two-finger scroll, pinch, typing, trackpad mode) is mapped back onto the shared window's coordinates.
  • Three parts: a Swift capture host, a TypeScript web viewer, and a small signaling service.

TrailMail

Predict a company's work emails, then send personal outreach from your own Gmail.

A Chrome extension that reads the profiles on a LinkedIn page, works out the company's email pattern from public data and drafts a personalized message for each person. It sends through your own Gmail and can show opens and clicks in the same panel.

  • One lookup credit resolves a whole company. Every other address at that domain is inferred locally from the pattern.
  • Send-only OAuth scope through Chrome's identity API. No client secret, and no server ever holds your mail.
  • One email per recipient, throttled, with a retry on rate limits and a per-person status.
  • Results are always labeled as predictions, never as verified addresses.

GitPixelPush

Your GitHub contribution graph, painted by you.

Sign in, sketch pixels onto your real contribution graph, review the exact plan and push. A browser-side engine writes clearly labeled, backdated empty commits through the Git Data API. Nothing is cloned and nothing is hidden.

  • The whole engine runs in the page. There is no backend doing git work, and your token never leaves the browser.
  • One Cloudflare Worker serves the site and handles the OAuth code exchange. That is the entire server.
  • Every commit is labeled as graph art, so the picture is disclosed rather than disguised as activity.

How I work

FOUR HABITS, EACH WITH A RECEIPT ABOVE
  1. 1

    Ground it before you generate it.

    A model's answer is only as good as the retrieval and the checks around it. The dispute assistant leans on filters, structured outputs and validation, not on a clever prompt.

  2. 2

    Verify, then say done.

    DialDo will not report success until it has evidence the task happened. I hold code to the same rule: tests, then a real run, then the claim.

  3. 3

    Ask for the least you need.

    A send-only mail scope. A token that never leaves the page. One window instead of the whole screen. The safest data is the data the system never holds.

  4. 4

    Say what state it is in.

    Every project here names what is untested or unfinished. This page counts only what you can check and links only what resolves.
